# Manufacturing & Design for Assembly

## PCB

Consider: - 2-layer manufacturing capability - trace/space - via size -
board edge tolerances - connector accessibility - component
availability - assembly side

## Enclosure

Consider: - wall thickness - draft angles - screw bosses - snap fits -
speaker mounting - display retention - button retention - PCB mounting -
battery retention - serviceability

## Potential assembly sequence

1.  Install speaker.
2.  Install PCB.
3.  Connect battery.
4.  Install display/interface.
5.  Install buttons.
6.  Verify wiring.
7.  Close enclosure.
8.  Install cosmetic shell.

## Battery safety

Use an appropriately protected cell/system. Secure the battery, protect
it from sharp edges and excessive heat, and verify the final charging
architecture before use.

## DFM questions

-   Can every component be sourced?
-   Can the PCB be assembled?
-   Can the enclosure be manufactured?
-   Can the battery be replaced?
-   Are connectors accessible?
-   Can the PCB be removed without damaging the enclosure?
