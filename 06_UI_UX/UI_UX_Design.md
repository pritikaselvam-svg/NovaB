# UI / UX Design

## Concept

Use an ambient display to surface useful information without requiring a
phone for every interaction.

## Information hierarchy

### Home

Connection, battery, playback state.

### Now Playing

Artwork, title, artist, playback state.

### Controls

Previous, play/pause, next, volume.

### Settings

Bluetooth, display and audio.

## Physical controls

Three buttons provide direct interaction. Exact mapping should be
validated through user testing.

## Design principles

-   Glanceable
-   Minimal
-   Clear state changes
-   Low interaction cost
-   Consistent hierarchy

## Validation questions

-   Can the current state be understood in two seconds?
-   Can common controls be used without a phone?
-   Is the display readable while worn?
-   Are icons understandable?
