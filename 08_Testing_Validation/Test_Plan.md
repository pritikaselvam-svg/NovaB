# Test & Validation Plan

## Mechanical

-   Earcup fit
-   PCB clearance
-   Button travel
-   Display visibility
-   Headband fit

## Power

-   USB input voltage
-   Charger output
-   Battery voltage/current
-   3V3 voltage
-   3V3 ripple
-   Regulator temperature
-   Idle current
-   Peak current

## Digital

-   ESP32 boot
-   GPIO
-   buttons
-   Hall sensor
-   display initialization
-   display refresh

## Audio

-   I²S configuration
-   amplifier initialization
-   speaker output
-   volume
-   noise
-   thermal behaviour

## PCB

-   visual inspection
-   solder bridge inspection
-   continuity
-   power-to-ground short check
-   rail voltage
-   connector pin verification
-   DRC

## Status language

**DESIGNED** = CAD/schematic/PCB exists.

**SIMULATED** = checked in software/design tools.

**PROTOTYPED** = physically manufactured.

**TESTED** = physically measured.

**VALIDATED** = tested successfully against a defined requirement.
