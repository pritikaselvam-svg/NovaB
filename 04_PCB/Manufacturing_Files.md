# PCB Manufacturing Deliverables

When the design is frozen, export: - Gerbers - Drill files - BOM -
Pick-and-place if outsourced - Fabrication drawing if required

## Pre-fabrication checklist

-   [ ] Schematic and PCB synchronized.
-   [ ] No unintended DRC violations.
-   [ ] Board outline closed.
-   [ ] Mounting holes verified.
-   [ ] Connector footprints physically verified.
-   [ ] ESP32 antenna keepout respected.
-   [ ] Silkscreen checked.
-   [ ] Polarity/orientation checked.
-   [ ] Battery connector polarity checked.
-   [ ] USB-C footprint verified.
-   [ ] Display connector pin numbering verified.
-   [ ] Manufacturer capabilities match trace/clearance choices.
